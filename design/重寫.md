## 故事主線（不變）

- 三個人：林宇（主角）、許帆（摯友）、方澄。
- 初秋傍晚，捷運站外下雨。林宇站在柱子後，手裡握著兩把傘（一把透明便利商店傘、一把傘骨歪掉的深藍傘）和一顆半融的薄荷糖，看著許帆把草木灰綠外套披在方澄肩上。
- 頂樓鐵絲網上三把刻著縮寫（L、X、F）的鎖；高中那年夏天的打賭：誰先開口坦白，誰就請一整個月的三分糖綠茶；方澄那把鎖從那天起沒人打開，鎖孔裡卡著林宇當年塞進去的糖；鎖開後掉出方澄畢業那天沒寄出的信。
- 二十四小時超商，收銀機跳著 17、19、21；『需要有人放棄結帳的權利。』；那一聲沒說出口的對不起化成紙鶴，投進收銀機。
- 最後在公車亭前抉擇：交出信、釋懷；或緊握雙傘退後、把秘密藏起來。
- 結局一：雨停、天亮，三輛不同號碼的公車同時進站，三人各自上車。結局二：雨永遠不停，方澄的外套褪色剝落、化成青綠螢火，許帆在水窪裡慟哭，青春凍結。

## 核心設定：意識回到意識中（作者 2026-10-18）

整個遊戲發生在林宇的意識裡。他的意識回到那個下雨的傍晚，困在裡面。

在意識裡：
- **說不出口的東西會變成看得見、拿得起的東西。** 第一分鐘就讓玩家知道這條規則（開場口袋裡的薄荷糖第一次發光時，林宇自己說出來）。
- **他藏起來的東西，只能用他藏的東西打開。** 所以方澄那把鎖要用薄荷糖開。
- **回憶是重播，不能改。** 玩家想在回憶裡做不同的選擇，意識會把他拉回真正發生過的那一下。
- **雨會一直下，直到他放手。** 雨停＝他走出意識；雨永遠不停＝他永遠困在裡面。
- **他每逃避一次，意識裡的方澄就褪一點色。** 外套的草木灰綠一路變淡，玩家看得見；壞結局她化成螢火，是他意識裡的她留不住了（不是現實裡的方澄死了）。

道具重新解釋：
| 道具 | 是什麼 |
|---|---|
| 半融的薄荷糖 | 他一直沒送出去的那句喜歡。方澄只吃薄荷糖；他口袋裡一直放著一顆，放到化了。 |
| 冰冷的指尖餘溫 | 他想替她擋風、最後沒有碰到的那一下。 |
| 一聲沒說出口的對不起（紙鶴） | 他欠方澄、也欠許帆的那句話。 |
| 未寄出的草木灰綠信封 | 方澄的信（內容見下）。 |
| 兩把傘 | 一把給自己，一把一直想給她、從沒給出去。 |

收銀機『需要有人放棄結帳的權利』：結帳＝計較誰欠誰、誰該得到誰。放棄結帳＝放棄佔有。

## 三人的心境（寫台詞以此為準；Claude 的提議）

- **林宇**：從十七歲就喜歡方澄，從沒說。看著許帆和方澄走近，他選擇站在柱子後面；對方澄好，也對許帆好，所以更說不出口。他的悔是一連串小小的逃避：假裝沒聽見她的嘆息、在雨裡默默抽回傘柄。
- **許帆**：方澄喜歡的是他。他也知道林宇的心意，所以在林宇面前從不牽方澄的手，替她披外套已經是他的極限。他欠林宇一句「我知道」。
- **方澄**：喜歡許帆，也知道林宇喜歡她。她怕任何一個人變成局外人，所以畢業那天寫了信給兩個人，沒寄出去。
- **信的內容**（方澄寫給林宇和許帆）：她知道、她選了誰、她不想讓任何一個人變成局外人；以及她一直等他們其中一個先開口。好結局林宇把信交出去，等於他終於說了「我知道，沒關係」。
- 好結局許帆那句「原來我們一直在等彼此先開口」，三個人都適用。

## 全劇流程與地圖（RPG）

```
序：捷運站出口（意識裡的雨，傍晚）
→【地圖一：捷運站出口與公車亭】自由走動；靠近公車亭到一條線就停下：「還不是現在。」
   ├─【地圖二：高中舊教學大樓頂樓】十七歲的夏天（回憶，可走）
   │    打賭 → 玩家選「說出來」也會被拉回「我把糖塞進了她的鎖孔」
   │    → 回到現在：用半融的薄荷糖開鎖 → 信、指尖餘溫
   ├─【地圖三：大學旁的二十四小時超商】十九歲的雨夜（回憶，可走）
   │    玩家選「把傘給她」也會被拉回「我抽回了傘柄」
   │    → 收銀機 17／19／21 → 用指尖餘溫 → 紙鶴「對不起」→ 投進收銀機
   └─ 兩段都走完（或玩家提早走向公車亭）→ 走進公車亭 → 最後的抉擇
→ 結局一〈各自的公車〉／結局二〈雨不會停〉
```

RPG 表現（讓玩家「感受」）：
- **距離**：在地圖一，越靠近公車亭，雨聲越小、心跳聲越大（BGM 與音效切換）；「還不是現在」那條線之前只能看。
- **被迫看著**：許帆替方澄披外套那一下，鏡頭停在那裡；可以選轉開頭，轉開也是一種選擇（記一次逃避）。
- **兩把傘**一直在背包。
- **褪色**：逃避的選擇累計一個變數；方澄外套的顏色跟著變淡（立繪三階段、或用色調演出），玩家看得到。最後抉擇時褪色程度影響方澄那幾句台詞的溫度，不改變結局走向（兩個結局由最後一選決定）。
- **意識的邊界**：意識裡的雨與光用環境燈光與 ambience 做（冷藍、草木灰綠的霧）；回憶地圖色調不同（頂樓是夏天的病態青綠夕照，超商是慘白日光燈）。
- 原版那些「取得／移除道具」的插件卡過場，改成地圖事件裡直接給、直接消耗。

## 兩個結局

- **〈各自的公車〉**：林宇走進公車亭，把信交給許帆和方澄，把多的那把深藍傘收起來：「我們三個人的平行線，其實不用勉強交會成三角形。」雨在一夜之後停了，天亮，三輛不同號碼的公車同時進站，三人各自上車。林宇醒來（走出意識）。
- **〈雨不會停〉**：林宇緊握雙傘退後。前面一路褪色的鋪陳在這裡收：外套剝落、方澄化成青綠螢火消失在雨裡、許帆在水窪裡慟哭。雨永遠不停，他困在意識裡。

## 美術

時空統一：台北，大學畢業那年初秋（現在）；台灣高中（回憶）。一律帶在場角色的定錨圖；先重做三人的定錨圖（便服、高中制服兩套）與行走圖、立繪要真透明。地景要寫清楚台灣特徵：捷運出口的造型與中文站名（可用虛構站名但要像台北捷運）、公車亭與中文站牌、台灣高中頂樓（水塔、鐵皮加蓋、生鏽鐵絲網、中文標語）、無品牌台灣超商（中文標示、關東煮、茶葉蛋鍋）。絕不出現日文與日式電線桿住宅街。
